Audit Signal Agent

여러 시스템에 흩어진 회계 데이터를 교차 검증해, 재무제표 겉면에는 드러나지 않는 문제를 찾아내는 LLM 에이전트. 이 페이지는 산출물만 모아 둔 곳이다.

감사조서 (규칙 기반 대조군) 발견사항 7건. 결론 → 요약표 → 원천 CSV 행까지 세 층으로 접혀 있다. 자바스크립트도 외부 참조도 없는 단일 HTML 문서다. API 키 없이 생성됨 실행 기록 테스트 98개, 채점기 자기 채점, 대조군 실행과 채점의 실제 터미널 출력을 그대로 붙여 둔 문서.

문서

  • 저장소와 기획서 (README) — 무엇을 만들었는지보다 왜 이 문제를 골랐는지
  • 데이터셋 명세 — 11개 파일, 4,200여 행, 5개 시스템
  • 정답지 — 심어 둔 문제 7개와 오탐 함정 4개
