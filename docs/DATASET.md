## 왜 파일을 11개로 쪼갰는가

실무에서 이 데이터는 한 곳에 없다. ERP 회계 모듈, 판매관리 시스템, WMS, 원가 시스템, 은행 CMS가 각각 따로 있고 서로 조인 키가 느슨하다. **한 파일만 보면 정상으로 보이지만 두 파일을 조인하면 문제가 드러나는 구조**를 재현하는 것이 이 데이터셋의 핵심이다.

```
data/raw/
├─ 회계 (ERP)
│  ├─ gl_journal.csv          2,394행  343KB   분개장 (전표 단위 차대)
│  └─ trial_balance.csv          14행    1KB   시산표 FY2023/FY2024
├─ 판매 (SFA)
│  ├─ sales_invoices.csv        624행   50KB   매출 송장 (인식일·인도조건)
│  └─ credit_notes.csv           47행    3KB   반품·매출취소 (2025년분 포함)
├─ 물류 (WMS)
│  └─ shipments.csv             624행   39KB   실제 출고일·도착일
├─ 원가

│  ├─ overhead_activities.csv     12행    1KB   활동별 간접비 풀 + 동인별 배부

├─ 자금
│  └─ bank_transactions.csv     296행   26KB   은행 거래내역 (2025년 초 포함)
├─ 구매
│  └─ purchase_orders.csv       150행   13KB   발주 품목명 + 계정처리
└─ 마스터·보고
   ├─ master_products.csv         3행    1KB
   ├─ master_customers.csv       13행    1KB   채널·계약형태·여신조건
```

## 조인 키

```
sales_invoices.invoice_no  ──1:1──  shipments.invoice_no
sales_invoices.customer_code ──N:1── master_customers.customer_code
sales_invoices.product_code  ──N:1── master_products.product_code
credit_notes.customer_code   ──N:1── master_customers.customer_code
purchase_orders.posted_account_code ──N:1── gl_journal.account_code
gl_journal.description       ── 문자열 포함으로 invoice_no / po_no 참조
bank_transactions.description ── 문자열 포함으로 GL 전표와 대응
master_customers.customer_name ── related_parties.party_name (부분일치)
```

마지막 두 줄이 의도적이다. **실무의 시스템 간 연결은 깔끔한 FK가 아니라 적요 문자열이다.** 이 지점이 LLM이 규칙 기반보다 유리한 영역이다.

## 검증된 정합성

`data/generate.py` 실행 후 다음이 성립한다.

| 검증 항목 | 결과 |
|---|---|
| GL 차변 합계 = 대변 합계 | 539,864백만원 일치 |
| 판매시스템 매출 합계 = GL 계정 501 대변 합계 | 88,000백만원 일치 |
| 제품별 매출 합계 = 설계값 | A 42,000 / B 28,000 / C 18,000 일치 |
| 활동별 간접비 풀 합계 = 제조간접비 총액 | 15,000백만원 일치 |
| 현행 배부액 합계 = ABC 배부액 합계 = 간접비 총액 | 15,000백만원 일치 |

**정합성이 깨진 지점은 전부 의도된 이상징후다.** 예: 매출인식일과 실제출고일의 불일치, 미수금 잔액의 8.7배 급증.

## 단순화한 부분 (의도적)

정직하게 밝혀 둔다. 아래는 실무와 다르지만, 심어둔 이상징후를 탐지하는 데 영향이 없다고 판단해 생략했다.

- **부가세를 반영하지 않았다.** 매출채권 = 매출액. 부가세 대급금 계정이 없다
- **재고 수량 수불을 생성하지 않았다.** 금액 기준 원가만 있고 단위당 원가·수량 롤포워드는 없다
- **대손충당금을 설정하지 않았다.** 채권 회수 가능성 평가는 별도 이슈이므로 제외했다
- **법인세·이연법인세가 없다.** 세무조정은 범위 밖이다
- **GL은 2024년만 존재한다.** FY2023은 시산표와 요약 재무제표로만 제공한다 (전기 대비 분석은 가능, 전기 전표 추적은 불가)
- **원가 배부는 연 단위 1회다.** 실무의 월별 예정배부·차이조정은 생략했다

## 라이선스와 성격

전부 **합성 데이터**다. 실제 회사·인물·거래와 무관하며, 등장하는 회사명·인명은 모두 가상이다. 실제 감사 결과나 특정 기업의 재무정보를 재현한 것이 아니다.
