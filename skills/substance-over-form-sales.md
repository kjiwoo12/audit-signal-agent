## 1. 목적

매출로 계상되었지만 고객이 실질적으로 재화를 통제하지 못하는 거래를 찾는다.

전형적인 형태는 **밀어내기(channel stuffing)**다. 기말에 대리점·유통사에 대량 출하하고 매출로 인식한 뒤, 다음 기에 대량 반품받는다. 개별 거래만 보면 정상 매출과 구별되지 않는다.

**이 절차의 어려운 점은 증거가 다음 회계기간에 있다는 것이다.** 반품은 익년에 발생하므로 당기 GL에는 존재하지 않는다. 당기 데이터만 보면 이 문제는 완전히 보이지 않는다.

## 2. 입력

```
sales_invoices.csv ──[customer_code]── master_customers.csv
                   └─[customer_code]── credit_notes.csv
master_customers.customer_name ──[부분일치]── related_parties.party_name
ar_aging.csv ──[customer_code]── (회수 실적 확인)
```

| 파일 | 사용 컬럼 |
|---|---|
| `sales_invoices.csv` | `invoice_no`, `revenue_date`, `customer_code`, `amount_krw` |
| `credit_notes.csv` | `credit_note_no`, `issue_date`, `customer_code`, `amount_krw`, `reason` |
| `master_customers.csv` | `customer_code`, `customer_name`, `channel`, `contract_type` |
| `related_parties.csv` | `party_name`, `relation` |
| `ar_aging.csv` | `customer_code`, `balance_krw`, 연령 구간별 금액 |

**반품 데이터는 반드시 보고기간 종료 후 3개월까지 포함한다.**

## 3. 결정론적 계산 (Python)

1. 거래처별 보고기간 출하액과 **후속 기간을 포함한** 반품액을 집계한다
2. 거래처별 반품률 = 반품액 ÷ 출하액 을 계산한다
3. 전체 평균 반품률과 거래처별 반품률의 편차를 계산한다
4. 거래처별 매출의 **기말 집중도**를 계산한다 (보고기간 마지막 달 매출 ÷ 연간 매출)
5. `ar_aging.csv`에서 거래처별 채권 잔액과 연령 분포를 가져온다
6. `master_customers.contract_type`, `channel` 값을 결합한다
7. 거래처명을 `related_parties.party_name`과 부분일치 대조한다

산출: 거래처별 출하액·반품액·반품률·기말집중도·채권잔액·계약형태·특수관계 여부

## 4. 판단 (LLM)

단일 지표로 판단하지 않는다. **아래 신호가 겹칠수록 실질이 위탁판매일 가능성이 높다.**

| 신호 | 의미 |
|---|---|
| 반품률이 전체 평균의 5배 이상 | 정상 품질 반품으로 설명되지 않음 |
| 매출이 기말 1개월에 집중 | 기간 목표 달성을 위한 출하 가능성 |
| `contract_type`이 위탁성·조건부 | 계약 자체가 반품권을 내포 |
| 채권이 전액 최근 구간에 있고 회수 실적 없음 | 실질적으로 대금이 회수되지 않음 |
| 반품 사유가 "재고조정", "판매부진" 등 | 품질 하자가 아닌 **미판매 반품** — 위탁의 결정적 징후 |
| 특수관계자에 해당 | 거래조건의 독립성 의심 |

**반품 사유를 반드시 읽는다.** "규격불량", "치수불량"은 정상적인 품질 반품이다. "미판매 재고 반품", "판매부진 반품"은 고객이 재화를 통제하지 못했다는 직접 증거다. 이 구분이 정상 반품과 위탁판매를 가르는 핵심이며, 금액만 집계해서는 절대 구별되지 않는다.

영향금액은 **반품된 금액**이 아니라 **반품이 예상되는 금액 전체**로 산정해야 한다. 다만 후속 반품 실적이 확정된 부분만 A등급 근거로 쓸 수 있다.

## 5. 기각 조건

- **전체 평균 수준의 반품률(제조업 통상 2~5%)** — 정상 영업 과정의 품질 반품이다. 반품이 존재한다는 사실 자체는 발견사항이 아니다
- **반품 사유가 품질·규격 하자인 건** — 통제는 이전되었고 사후 하자로 반환된 것이다. 수익 인식 자체는 정당하다
- **기말 집중도가 높지만 반품률이 정상인 거래처** — 계절성이다. 두 신호가 함께 나타나야 의미가 있다
- **특수관계자 거래라는 사실만으로** — 특수관계자 거래는 그 자체로 부정이 아니다. 공시 대상일 뿐이며, 거래조건의 비독립성 증거가 함께 있어야 발견사항이 된다
- **후속 반품 데이터가 없는 기간의 거래** — 반품이 아직 발생하지 않았는지, 데이터가 없는지 구별할 수 없다. 근거등급 C로 낮춘다

## 6. 근거 요구

- 대상 거래처의 `customer_code`와 `customer_name`
- 출하 `invoice_no`와 대응하는 반품 `credit_note_no`를 **쌍으로** 제시
- 반품률 비교표 (대상 거래처 vs 전체 평균)
- `contract_type` 원본 값, 해당 시 `related_parties`의 `relation` 원문

반품 `credit_note_no`를 대지 못하면 근거등급 B 이하다.

## 7. 산출

```
발견사항: 특정 거래처군에 대한 기말 대량출하가 익년 대량반품으로 이어짐 — 실질 위탁판매 가능성
위험등급: {High if 금액 >= 세전이익 5%}
추정 영향: 매출 과대 {후속 반품 확정액}, 추가로 미반품 잔액 {금액}에 대한 반품충당부채 검토 필요
근거: {거래처} SI2024-XXXXX 외 N건 / 대응 반품 CN2025-XXXX 외 M건
      반품률 {X}% vs 전체 평균 {Y}%
      contract_type = "{원본값}", 특수관계: {relation 원문 또는 해당없음}
추가 확인 절차:
  - 해당 거래처와의 판매계약서상 반품권·소유권 이전 조항 확인
  - 대리점 재고 실사 또는 재고보고서 징구
  - 보고기간 이후 추가 반품 발생 여부 확인 (조회 기간 연장)
담당자 질문:
  - 대리점 출하분의 매출 인식 시점을 출하 시점으로 보는 근거는 무엇인가
  - 대리점의 미판매 재고에 대한 반품 의무가 계약상 존재하는가
```
